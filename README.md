# DemoBlaze Functional & Automation Test Suite

This repository contains the functional test plan, automated test suite (Selenium WebDriver + Java + TestNG), and defect reports for `demoblaze.com`.

## Prerequisites
* **Java SDK**: 17 or higher
* **Build Tool**: Maven 3.8+
* **IDE**: IntelliJ IDEA (recommended)
* **Browser**: Google Chrome (managed via WebDriverManager)

## How to Run the Tests

### Option 1: Via Terminal (Maven)
Run all automated test cases using:
```bash
mvn clean test
